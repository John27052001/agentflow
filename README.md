# 🚀 AgentFlow — AI Workflow Automation Platform

AgentFlow is a modern AI-powered workflow assistant that transforms messy notes, customer feedback, standup updates, and bug reports into structured summaries and actionable tasks.

Built with Next.js, TypeScript, Tailwind CSS, and modern full-stack engineering practices.

---

## ✨ Features

- 🧠 AI-style workflow summarization
- ✅ Action item extraction
- 📝 Multiple workflow modes
  - Meeting Notes
  - Customer Feedback
  - Bug Reports
  - Daily Standups
- 📚 Workflow history with persistence
- 🗑️ Delete individual workflows
- 📋 Copy summaries and action items
- ⚡ Real-time SaaS-style UI
- 🌙 Modern dark glassmorphism interface
- 💾 localStorage persistence
- 🔄 Dynamic workflow generation logic

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/John27052001/agentflow.git
```

### 2. Navigate into the project

```bash
cd agentflow
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run development server

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```
